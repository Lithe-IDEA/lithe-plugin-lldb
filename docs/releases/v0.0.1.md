0.0.1 是按插件契约 v0 重新发布的首个版本。

功能：
- 用你电脑上的 `lldb-dap` 调试 C / C++ / Objective-C / Swift / Rust 程序。
- 插件设置 Program 指定要调试的程序；留空时依次在当前文件旁、项目根目录和 `build/` 下按文件名查找。
- 调试控制台里用 `` ` `` 加 lldb 命令，补全来自插件声明的命令列表和 `lldb-dap`。

权限：`debug.launch`。

兼容性：
- 只能装进新版 Lithe 桌面端（`desktop-v*` 预发布），旧版 macOS Lithe 无法安装。
- 本版本是预发布，Lithe Store 的自动追踪会跳过它。
