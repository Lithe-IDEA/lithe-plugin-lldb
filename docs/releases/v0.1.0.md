0.1.0 可以在 Lithe 里安装 `lldb-dap`。

功能：
- 找不到 `lldb-dap` 时（`PATH` 和 `xcrun --find lldb-dap` 都没有），插件详情里调试能力的卡片上有 **安装** 按钮：
  Lithe 用 Homebrew 运行 `brew install lldb`，装好后在 `$(brew --prefix lldb)/bin` 里找到 `lldb-dap` 并记下这个目录，
  之后调试直接用它，不需要改 `PATH`。
- 需要先装好 Homebrew；Lithe 在 `PATH`、`/opt/homebrew` 和 `/usr/local` 里找 `brew`。安装需要联网，会下载 LLDB 和它依赖的
  LLVM、Python（几百 MB，装好后超过 1 GB），最长等一小时。LLDB 和 LLVM 都是 keg-only，不会替换系统的 `lldb`、`clang`，
  卸载插件时也不删除。
- Homebrew 只给 Apple Silicon 上的 macOS 15 及以上提供预编译包；Intel Mac 和更早的 macOS 上会从源码编译，可能超过
  一小时的时限，这时请用 Xcode 或命令行工具自带的 `lldb-dap`。
- 已经有 Xcode 或 Xcode 命令行工具自带的 `lldb-dap` 时，行为和 0.0.1 相同，不会出现安装按钮。

验证：
- CI 在 macOS 上用 `clang -g` 编译一个 C 程序，按清单的声明运行两次调试会话（`scripts/test.mjs`）：一次用 `xcrun`
  找到的 Xcode 自带 `lldb-dap`，一次用按安装器声明执行 `brew install lldb` 后、从目录探针给出的目录启动的
  `lldb-dap`；两次都命中断点、读出局部变量并正常退出。
- 清单用 Rust Core 的清单校验、工具注册、发现计划和安装计划检查过；宿主端到端测试固定到包含 `commandInstallers` 的宿主版本。

权限：新增 `commands.install`，只在你点击 **安装** 并确认后使用。

兼容性：
- 需要支持 `commandInstallers` 的 Lithe 桌面端（1lck/Lithe-IDEA#1971）；更早的桌面端请继续用 0.0.1。
- 只能装进新版 Lithe 桌面端（`desktop-v*` 预发布）。
